# 北海道冬日旅行 V3

静态旅行手账，电脑和手机浏览器均可查看。

## 在 GitHub Pages 发布

1. 新建一个公开仓库，例如 `hokkaido-trip`。
2. 上传本文件夹里面的全部文件，保证仓库根目录直接有 `index.html`，同时保留 `vendor` 文件夹。不要只上传 ZIP，也不要在 `index.html` 外多套一层文件夹。
3. 打开仓库 Settings → Pages。
4. Source 选择 Deploy from a branch，Branch 选择 main，目录选择 /(root)，然后 Save。
5. 等待 Pages 显示发布完成，用页面提供的 Visit site 打开真实访问链接，再发给朋友。

`.nojekyll` 是空文件，用于直接提供静态网页资源。不需要安装依赖或填写构建命令。

各自浏览器独立保存行程选择和车票。电脑本地网页中的记录不会自动同步到这个网址。

外部街道图、导航及官网链接需要联网；基础地图轮廓随页面提供。

[GitHub Pages 官方发布说明](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)
