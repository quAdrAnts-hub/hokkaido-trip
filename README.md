# 北海道冬日旅行

**Hokkaido Winter Journey · V3**

一份供同行朋友查看的冬季旅行手账。将航班、跨城交通、每日路线、住宿与餐饮整理在同一页面，方便出发前讨论，也方便旅途中随时查看。

**旅行日期**：2026 年 12 月 23 日 — 2027 年 1 月 7 日  
**行程长度**：16 天 · 页面时间均为日本当地时间

## 行程路线

成田 → 函馆 → 洞爷湖 → 登别 → 旭川 → 旭岳 → 札幌 → 成田

以旭川为住宿点安排美瑛、富良野与市区游览；从札幌往返小樽。城际与市内移动以公共交通为主。

## 页面内容

| 内容 | 说明 |
| --- | --- |
| 航班与车票 | 添加、编辑机票与跨城车票，填写时间、购票状态及备注 |
| 当天地图 | 景点从 1 编号，住宿用房子图标；支持双指缩放、大图查看与交通联动 |
| 每日行程 | 按日期切换时间线，住宿、餐食与景点直接嵌入当天 |
| 可选路线 | 部分日期支持 A/B 切换，尚未完成的路线可进入后续日期候补 |
| 交通与门票 | 展开查看乘车方法、参考耗时、购票说明与官方入口 |
| 食物 | 早餐、午餐、晚餐、零食便利店四个入口；下午茶与饭后甜点放在相应餐次里 |
| 零食包装 | 点击查看官方商品参考图，也可自己添加零食、购买地点、备注与图片链接 |
| 保存与分享 | 本地保存填写内容，可导出 JSON 文件，在其他设备或朋友的浏览器中导入 |

页面使用浅灰背景、白色卡片、系统字体与蓝色交互提示。电脑端并列查看机票，手机端左右滑动；日期条与餐食分段控件提供清楚的选中状态。切换采用轻量动效，并尊重系统“减少动态效果”设置。日期选择后直接显示当天内容，地图随行程同步更新。

## 使用方式

- **选日期**：查看当天的路线、住宿和餐饮候选。
- **选行程**：在提供 A/B 选项的日期切换路线；标记“今天已去过”后，对应路线会从后续候补中移除。
- **查交通**：展开地点之间的交通条，查看站点、购票要求与导航。
- **看地图**：手机双指缩放、单指移动；点击“放大”进入大图，“回到当天”恢复所选日期范围。底图自动尝试可用来源，展开交通段后显示相应站点。
- **补票务**：在原卡片点“编辑”或“填写车票”，也可以添加新票。时间保存后立即替换卡片里的“待补”；购票状态需手动标记。编辑机票仅更新机票卡，不会自动重排行程。
- **记零食**：打开当天“零食便利店”，点“添加零食”；“看包装”可展开图片与来源。
- **带走填写**：页面底部展开“保存与分享”，导出文件；在另一台设备打开本页并导入即可。

行程选择、完成标记、票务与自添零食保存在当前浏览器中，不会自动同步给其他人或其他设备。分享网址或上传网页文件不会带上本地填写；导入前会显示数量并确认是否替换。

1/6 航班为 **18:10 新千岁 → 约 19:55 成田**，落地后使用酒店接送。当天预留 13:30 酒店取行李、14:15 左右机场 JR、15:00 左右到机场；地面交通为目标时间，冬季实际班次仍待确认。

## 查看与分享

### 本地查看

下载并解压完整项目，使用浏览器打开 `index.html`，无需安装依赖或运行构建命令。本发布包采用平铺结构，所有网页、脚本、样式和图片放在同一文件夹内，请保留全部文件。

### 在线分享

项目可使用 GitHub Pages 托管。在仓库 **Settings → Pages** 中，将发布来源设置为 **Deploy from a branch**，选择 **main** 分支与 **/(root)** 目录。

等待发布完成后，使用 Pages 页面提供的网址访问或分享给同行朋友。

## 项目文件

- `index.html`：页面结构
- `trip-data.js`：行程、地点、住宿、交通及门票资料
- `food-data.js`：餐饮候选、地址与小食参考
- `app.js`：地图联动、日期切换、路线选择与本地保存
- `flight-editor.js`、`flight-editor.css`：可编辑机票卡
- `snack-images.js`：官方包装图与来源
- `snack-book.js`：包装图弹窗、个人零食添加与编辑
- `travel-backup.js`、`travel-backup.css`：填写内容的导出、导入
- `styles.css`、`revision.css`、`food.css`：页面布局与响应式样式
- `apple-ui.css`：统一字体、色彩、卡片、控件与动效的视觉样式
- `geography.js`：基础地图轮廓
- `leaflet.js`、`leaflet.css` 与 `.png` 文件：地图组件及图片资源
- `LICENSE`、`topojson-LICENSE.txt`、`world-atlas-LICENSE.txt`：相应第三方组件与地图数据的许可证

使用 HTML、CSS 与原生 JavaScript 编写，地图交互基于 Leaflet。

## 信息说明

行程中的时间与交通耗时用于出行参考，实际乘车以票面及运营商公告为准。尚未公布的冬季班次、年末营业及预约时段保留“待确认”标记。

默认使用[日本国土地理院标准地图](https://maps.gsi.go.jp/development/ichiran.html)，备用为[OpenStreetMap](https://www.openstreetmap.org/copyright)。详细底图加载失败时，会尝试另一底图；均不可用时保留路线并提示重试。Google Maps 按钮可打开当前地图位置，每个地点仍附独立导航入口。

基础轮廓随项目提供；详细底图、包装图、Google Maps 导航及官方购票页面需要联网。地图连线表示到访顺序，具体行走路线请以导航与现场情况为准。地图数据来源说明可在页面内展开查看。

包装图片来自商品官方页面，点击可查看出处。部分为同类商品或历史季节包装，图片下方会注明；未确认的商品保留提示，不替配照片。图片载入失败时可打开商品资料或搜索包装。
